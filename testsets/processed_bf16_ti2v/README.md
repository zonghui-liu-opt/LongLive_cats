# BF16 TI2V cat action sequence

Generated by `scripts/prepare_cat_ti2v_testset.py`. The PNG and TXT share a stem so `ImagePromptDataset` can load them directly.

The prompt is intentionally one non-empty line: splitting the three actions across lines would make the current loader mark them as separate scene cuts.

Use `configs/inference_i2v_cat_sequence_bf16.yaml` after setting a merged I2V BF16 checkpoint compatible with the configured sampling steps.
